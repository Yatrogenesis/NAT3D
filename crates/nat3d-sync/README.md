# nat3d-sync

Device synchronization for NAT3D - iPad input, Apple Pencil, Bonjour discovery.

Part of [NAT3D](https://github.com/Yatrogenesis/NAT3D). The whole stack in one dependency: the [`nat3d`](https://crates.io/crates/nat3d) crate.

```toml
[dependencies]
nat3d-sync = "0.2"
```

## Modules

- `discovery`
- `input`
- `protocol`
- `render_farm`
- `scene_crdt`

API reference: <https://docs.rs/nat3d-sync>
