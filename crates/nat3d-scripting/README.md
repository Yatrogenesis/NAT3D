# nat3d-scripting

Scripting interface for NAT3D - Python bindings via PyO3, Rust API.

Part of [NAT3D](https://github.com/Yatrogenesis/NAT3D). The whole stack in one dependency: the [`nat3d`](https://crates.io/crates/nat3d) crate.

```toml
[dependencies]
nat3d-scripting = "0.2"
```

## Modules

- `ai`
- `macros`
- `python`
- `rust_api`

API reference: <https://docs.rs/nat3d-scripting>
