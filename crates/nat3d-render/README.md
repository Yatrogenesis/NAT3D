# nat3d-render

Rendering engine for NAT3D - wgpu backend, PBR, raytracing, post-processing.

Part of [NAT3D](https://github.com/Yatrogenesis/NAT3D). The whole stack in one dependency: the [`nat3d`](https://crates.io/crates/nat3d) crate.

```toml
[dependencies]
nat3d-render = "0.2"
```

## Modules

- `backend`
- `lighting`
- `pipeline`
- `postprocess`
- `raytracing`

API reference: <https://docs.rs/nat3d-render>
