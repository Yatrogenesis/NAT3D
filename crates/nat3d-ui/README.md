# nat3d-ui

User interface for NAT3D - egui-based panels, tools, viewport, input handling.

Part of [NAT3D](https://github.com/Yatrogenesis/NAT3D). The whole stack in one dependency: the [`nat3d`](https://crates.io/crates/nat3d) crate.

```toml
[dependencies]
nat3d-ui = "0.2"
```

## Modules

- `app`
- `input`
- `panels`
- `shortcuts`
- `theme`
- `tools`
- `viewport`

API reference: <https://docs.rs/nat3d-ui>
