# nat3d-physics

Physics simulation for NAT3D - rigid bodies, soft bodies, cloth, fluids (Navier-Stokes), particles.

Part of [NAT3D](https://github.com/Yatrogenesis/NAT3D). The whole stack in one dependency: the [`nat3d`](https://crates.io/crates/nat3d) crate.

```toml
[dependencies]
nat3d-physics = "0.2"
```

## Modules

- `cloth`
- `engine`
- `fluids`
- `particles`
- `presets`
- `rigid_body`
- `soft_body`
- `quantum`
- `xpbd`

API reference: <https://docs.rs/nat3d-physics>
