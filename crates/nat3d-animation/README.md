# nat3d-animation

Animation system for NAT3D - keyframes, curves, rigging, skinning, IK.

Part of [NAT3D](https://github.com/Yatrogenesis/NAT3D). The whole stack in one dependency: the [`nat3d`](https://crates.io/crates/nat3d) crate.

```toml
[dependencies]
nat3d-animation = "0.2"
```

## Modules

- `constraints`
- `curve`
- `drivers`
- `keyframe`
- `motion`
- `nla`
- `rigging`
- `shape_keys`
- `timeline`

API reference: <https://docs.rs/nat3d-animation>
