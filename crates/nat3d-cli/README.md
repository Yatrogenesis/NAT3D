# nat3d-cli

Command-line interface for NAT3D - batch rendering, format conversion, benchmarks.

Part of [NAT3D](https://github.com/Yatrogenesis/NAT3D). The whole stack in one dependency: the [`nat3d`](https://crates.io/crates/nat3d) crate.

Install: `cargo install nat3d-cli`. The binary is called `nat3d`. Run `nat3d --help` for the commands.
