# nat3d-core

Core data structures and types for NAT3D - documents, geometry, transforms, scene graph.

Part of [NAT3D](https://github.com/Yatrogenesis/NAT3D). The whole stack in one dependency: the [`nat3d`](https://crates.io/crates/nat3d) crate.

```toml
[dependencies]
nat3d-core = "0.2"
```

## Modules

- `document`
- `error`
- `geometry`
- `hierarchy`
- `history`
- `layer`
- `material`
- `selection`
- `stylus`
- `transform`

API reference: <https://docs.rs/nat3d-core>
