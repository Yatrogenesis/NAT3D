# nat3d-mobile

Android/iOS native wrapper for NAT3D - Pure and Secure Version.

Part of [NAT3D](https://github.com/Yatrogenesis/NAT3D). The whole stack in one dependency: the [`nat3d`](https://crates.io/crates/nat3d) crate.

```toml
[dependencies]
nat3d-mobile = "0.2"
```

## Modules

- `ios`

API reference: <https://docs.rs/nat3d-mobile>
