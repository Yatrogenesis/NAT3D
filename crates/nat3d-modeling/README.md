# nat3d-modeling

Modeling tools for NAT3D - polygon modeling, NURBS, sculpting, CAD, modifiers.

Part of [NAT3D](https://github.com/Yatrogenesis/NAT3D). The whole stack in one dependency: the [`nat3d`](https://crates.io/crates/nat3d) crate.

```toml
[dependencies]
nat3d-modeling = "0.2"
```

## Modules

- `cad`
- `modifiers`
- `nurbs`
- `polygon`
- `sculpt`
- `sketch2mesh`
- `spectral`
- `uv`

API reference: <https://docs.rs/nat3d-modeling>
