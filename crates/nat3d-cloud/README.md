# nat3d-cloud

Cloud rendering integration for NAT3D - AWS, GCP, Azure, custom servers.

Part of [NAT3D](https://github.com/Yatrogenesis/NAT3D). The whole stack in one dependency: the [`nat3d`](https://crates.io/crates/nat3d) crate.

```toml
[dependencies]
nat3d-cloud = "0.2"
```

## Modules

- `client`
- `job`
- `providers`
- `transfer`

API reference: <https://docs.rs/nat3d-cloud>
