# nat3d-app

Main application for NAT3D - desktop GUI application.

Part of [NAT3D](https://github.com/Yatrogenesis/NAT3D). The whole stack in one dependency: the [`nat3d`](https://crates.io/crates/nat3d) crate.

Install: `cargo install nat3d-app`. Python scripting, iPad input and file dialogs are optional features.

## Modules

- `license`
- `startup`
- `viewport`
- `compositor`
- `console`
- `nodes`
- `panels`
- `state`
- `tools`
- `weight_paint`

API reference: <https://docs.rs/nat3d-app>
