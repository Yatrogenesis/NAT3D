# nat3d-math

Mathematical utilities for NAT3D - linear algebra, FFT, optimization, interpolation, noise.

Part of [NAT3D](https://github.com/Yatrogenesis/NAT3D). The whole stack in one dependency: the [`nat3d`](https://crates.io/crates/nat3d) crate.

```toml
[dependencies]
nat3d-math = "0.2"
```

## Modules

- `easing`
- `geometry`
- `interpolate`
- `noise`
- `spatial`
- `spline`

API reference: <https://docs.rs/nat3d-math>
