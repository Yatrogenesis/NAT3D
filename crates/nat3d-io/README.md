# nat3d-io

Import/Export for NAT3D - native format, OBJ, glTF, FBX, STEP, STL, images.

Part of [NAT3D](https://github.com/Yatrogenesis/NAT3D). The whole stack in one dependency: the [`nat3d`](https://crates.io/crates/nat3d) crate.

```toml
[dependencies]
nat3d-io = "0.2"
```

## Modules

- `crypto`
- `formats`
- `image`
- `video`

API reference: <https://docs.rs/nat3d-io>
